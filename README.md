# website

Static site (no build step needed to deploy; publish the repo root).

- `index.html` — home page (no project list).
- `data/cases.json` — project data (groups + cases).
- `work.html` — "Our work" page with all projects and filters, generated by `python3 build.py`.
- `work/<id>.html` — one page per project, generated by `python3 build.py` from `data/cases.json`.
- `assets/site.css`, `assets/art.js` — shared styles and card illustrations.
- Project images are expected in `assets/cases/` (missing images fall back to the SVG illustration).

After editing `data/cases.json`, run `python3 build.py` and commit the result.
