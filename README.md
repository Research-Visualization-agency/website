# website

Static site (no build step needed to deploy; publish the repo root).

- `index.html` — home page, includes the project data (`#casesData`).
- `work/<id>.html` — one page per project, generated by `python3 build.py` from the data in `index.html`.
- `assets/site.css`, `assets/art.js` — shared styles and card illustrations (`art.js` is generated).
- Project images are expected in `assets/cases/` (missing images fall back to the SVG illustration).

After editing the project data in `index.html`, run `python3 build.py` and commit the result.
